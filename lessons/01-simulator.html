第 1 課

模擬器入門

先在電腦裡安心摔機，實機之前把手感練起來。

🎯 學習目標

  • 能夠說出遙控器兩支搖桿各自控制什麼（油門、偏航、俯仰、橫滾）。
  • 能夠把遙控器連上電腦並在模擬器裡通過校正。
  • 能夠在模擬器裡讓飛機離地並完成一次不撞毀的短飛行。

🧰 事前準備

  • 一台能跑 3D 遊戲的電腦。
  • 一支可以用 USB 連電腦的遙控器（Radio）；沒有的話也可以先用手把練習。
  • 一套 FPV 模擬器，例如 Liftoff、VelociDrone、DRL Simulator 等（各有收費或免費版本，請自行查證）。

🪜 練習步驟

  1. 先認識搖桿（常見的 Mode 2）：左桿上下是油門（Throttle）、左右是偏航（Yaw）；右桿上下是俯仰（Pitch）、左右是橫滾（Roll）。
  2. 用 USB 線連接遙控器與電腦，並依遙控器說明選擇 USB 搖桿模式。
  3. 開啟模擬器，進入搖桿校正畫面，照指示依序撥動各軸。
  4. 確認四個軸的方向正確：推油門時飛機上升、右桿往前時機頭下壓。
  5. 選擇姿態模式（Angle mode）的新手設定與開闊場景。
  6. 輕輕推油門讓飛機離地，目標是離地 1–2 公尺，不求飛遠。
  7. 每次練 10–15 分鐘就休息，寧可多練幾次，也不要一次硬撐。
💡 小提醒：搖桿動作越小越好，新手最常見的狀況就是「推太大」。

⚠️ 常見錯誤

推油門飛機沒反應 → 搖桿軸沒校正或對應錯 → 重新校正，並檢查油門軸是否對應正確。
飛機一離地就亂飄 → 搖桿修正量太大 → 縮小動作幅度，並降低模擬器的難度設定。
往前推卻往後退 → 軸方向反了 → 回校正畫面檢查俯仰軸方向。

✅ 過關檢查

🛟 安全提醒：請依當地法規與場地規定飛行，並留意周遭人員安全。
